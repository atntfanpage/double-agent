# Double Agent

A daily general-knowledge deduction puzzle. Each puzzle has two rules: one printed, one hidden. Work out the hidden rule from the examples, then name three answers that fit both. Rarer answers score more.

Play: https://atntfanpage.github.io/double-agent/

Answer lists are built from [Wikidata](https://www.wikidata.org) (CC0). Photos come from Wikimedia Commons and other openly licensed sources; see `img/credits.json` for attribution.
